# DraveComic

Maak je eigen stripboek: vakjes, plaatjes, zelf tekenen in lagen (ook met een tekentablet: druk = lijndikte), praatballonnen en geluidswoorden, achtergronden laag op laag, een personage-kast, een verhaal-planner die de bladzijden voor je maakt, een voor- en achterkant en groot bladeren (ook twee naast elkaar). Bewaar als PDF of plaatjes, of maak hem klaar voor de drukker (binnenwerk + kaft met rug).

## ⬇️ Downloaden (Windows, geen Python nodig)

### [👉 Download DraveComic 0.6.0](https://github.com/mbrv4ever/DraveComic/releases/latest)

1. Klik op de link en download het **.zip**-bestand.
2. Pak het uit: rechtsklik → **Alles uitpakken...**
3. Dubbelklik op **DraveComic.exe**.

> Zie je een blauw scherm "Windows heeft uw pc beschermd"? Klik op **Meer informatie** → **Toch uitvoeren**.

## Vanaf de broncode

Installeer Python 3.10 – 3.13 en de benodigde pakketten (zie `requirements.txt` als die er is), en start het hoofdbestand (`.py`). Eventuele `.bat`-bestanden doen dit voor je.
